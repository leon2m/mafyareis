# Statik site

GitHub Pages'te yayında: https://leon2m.github.io/mafyareis/ (depo: leon2m/mafyareis, yalnızca bu klasörün içeriği).

- `gizlilik.html` → App Store Connect "Gizlilik Politikası URL'si"
- `destek.html` → "Destek URL'si"
- `config/v1.json` → oyundaki `ConfigService.CONFIG_URL`
- `app-ads.txt` → AdMob gelince alan adının köküne konur

Güncellemek için bu klasörü depoya kopyalayıp push et. Uygulama yayına girince `index.html`'deki
"yakında" satırını App Store bağlantısıyla (https://apps.apple.com/tr/app/id6815187839) değiştir.
